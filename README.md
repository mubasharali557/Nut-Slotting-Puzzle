# color-Sort-Puzzle

A modern, responsive, fluid liquid-sorting puzzle game built with React, Vite, PixiJS, Tailwind CSS, and Lucide Icons.

## Features

- **100 Playable Stages**: Progressive puzzle stages with solvable liquid alchemy mechanics.
- **Responsive & Mobile-Friendly**: Adapts smoothly to mobile devices (portrait & landscape) and desktop screens with dynamic 100dvh viewport and safe-area support.
- **Stationary Tube Selection & Unrestricted Pouring**: Stationary glowing rim selection with unrestricted color pouring into any container with open capacity.
- **Theme & Bottle Skin Shop**: 5 distinct themes (Apothecary, Cozy Winter, Fantasy Castle, Cosmic Aurora, Golden Sunset) and 4 bottle skins (Classic Glass, Royal Potion, Golden Flask, Cyber Neon).
- **Celebration Effects**: Festive victory bunting flags, rotating sunburst rays, and continuous celebratory confetti cannons upon completing stages.
- **Game Audio**: Immersive sound effects for pouring, chimes, bottle selection, and victories.

## Getting Started

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

### Building for Production

```bash
npm run build
```
